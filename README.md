# Todo Application

A simple, elegant todo application built with React, TypeScript, and Vite that persists tasks in local storage.

## Features
- Create, complete, and delete tasks
- Persistent storage using browser's localStorage
- Clean and responsive UI
- Showing remaining tasks
- One-click clear completed tasks
- Fully typed with TypeScript

## Tech Stack

- **React 19:** For building the user interface
- **TypeScript:** For type safety and better developer experience
- **Vite:** For fast development and optimized builds
- **localStorage API:** For persisting todo items between sessions
- **Tailwind CSS:** For styling components
- **Lucide React:** For beautiful, customizable icons

# Getting Started

## Prerequisites
- Node.js 18.x or later
- npm or yarn

## Installation

1) Clone the repository
```bash
git clone https://github.com/preetjasani1708/todo-app.git
cd react-todo-app
```

2) Install dependencies
```bash
npm install
# or
yarn
```

3) Start the development server
```bash
npm run dev
# or
yarn dev
```

4) Open your browser and navigate to [http://localhost:5173](http://localhost:5173)


## Building for Production
```bash
npm run build
# or
yarn build
```
This will generate a production-ready build in the **dist** directory.

## Run Build 
```bash
npm run preview
# or
yarn preview
```
